# ⚡ AuraVault - Premium E-Commerce Website

Welcome to **BhaiVerse**, a sleek, modern, and responsive e-commerce web application built using pure HTML, CSS, and JavaScript.

## ✨ Features
- 🌙 **Dark/Light Theme:** Dynamic theme switcher.
- 🛒 **Interactive Cart Drawer:** Add items, manage quantities, and see live pricing calculations.
- 🎯 **Category Filter & Search:** Real-time search and filter products by category.
- 📱 **Responsive Design:** Mobile and desktop friendly UI.

## 🚀 Live Preview / Local Setup
1. Clone or download this repository.
2. Open `index.html` in VS Code.
3. Right-click on `index.html` and choose **Open with Live Server**.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Variables & Flexbox/Grid)
- JavaScript (Vanilla JS - ES6)
- FontAwesome Icons
